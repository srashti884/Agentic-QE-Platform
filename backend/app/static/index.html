6-Layer Architecture Hierarchy

01 Layer 1: Presentation Layer (FastAPI HTML/CSS/JS)

High-performance zero-node dashboard. Displays scenario selection, 5-stage stepper, deterministic prioritization tables, factor breakdowns, and human review gates.

backend/app/static/*, backend/app/main.py
HTML5 + CSS3 + Vanilla JS
02 Layer 2: API Gateway Layer

Exposes REST endpoints, validates request/response schemas with Pydantic, enables CORS, and serves static frontend assets directly.

backend/app/main.py, backend/app/routes/*
FastAPI + Pydantic v2 + Uvicorn
03 Layer 3: Agent Orchestration Layer

Coordinates sequential agent execution: Change Analysis -> Test Impact Analysis -> Deterministic Prioritization -> Explainability -> Audit Logging.

backend/app/orchestrator/workflow.py
WorkflowOrchestrator Pipeline
04 Layer 4: Specialized QE Agents

Encapsulates specialized QE capabilities: ChangeAnalyzerAgent, ImpactAnalyzerAgent, PrioritizerAgent, and ExplainabilityAgent implementing BaseAgent.

backend/app/agents/*
BaseAgent Abstraction
05 Layer 5: Deterministic Prioritization Engine

Computes objective test scores using verified factors: Endpoint match (+35), Criticality (+25), Failure history (+25), Breaking change (+10), Flakiness (+5). Zero ML hallucination.

backend/app/agents/prioritizer.py, backend/app/agents/explainability.py
Multi-factor Scoring Engine
06 Layer 6: Persistence & Audit Layer

Encapsulates data access for API changes, regression test catalogs, and immutable event logs (PIPELINE_RUN, HUMAN_REVIEW).

backend/app/repositories/*, backend/data/*.json
Repository Pattern + JSON
